# Mindmap Reader

本を読みながら、内容を構造化して理解するためのマインドマップWebアプリ。
ADHD/ASDなど「頭の中を整理するのが苦手」な人が、迷わず・少ない手数で使えることを重視しています。

設計書は [docs/specs/](docs/specs/README.md)、進め方は [docs/PLAN.md](docs/PLAN.md) にあります。

## 現在の段階

**段階1：操作感の検証（PoC）**。キャンバスの操作が気持ちよくできるかを確かめるための試作です。

できること

- 2つのモード（作成後もツールバーで切り替え可。切り替えてもデータは消えない）
  - **読書**：本 → 章（要点 / 引用 / 気づき）/ 全体の気づき・感想 / 全体で行動に移すこと の型から始まる
    - ページ番号（p.42、p.42-45、p.12, 15）を項目に付けられる。数字・「-」・「,」以外は入力できず、全角数字は半角に、逆順の範囲（45-42）は自動で 42-45 に直す
    - 「引用」と「自分の言葉」を見た目で区別できる
    - 「＋ 章を追加」で次の章を型ごと追加（最後の章の下、全体のまとめの上。追加した章は少しの間ハイライト）
  - **シンプル**：余計な項目のない普通のマインドマップ
- 項目の追加・編集・削除（キーボードだけで完結）
- 自動整列（レイアウトは常に自動。位置調整の手間なし）
- ドラッグで別の項目に重ねると付け替え（移動先の強調表示・新しい線のプレビュー・案内文つき）
- 編集中は文字数に合わせて項目が横に伸びる（周りの項目も自動でずれる）
- 折りたたみ・展開、ズーム・パン
- 元に戻す / やり直す
- メモ：項目ごとに長めのメモ（M。マップには ≡ の印だけ）。コピー・Markdown（「> 」の行）でも残る
- マップ内の検索（⌘F / Ctrl+F）：メモも、たたまれた中も探す。Enter で次、Shift+Enter で前
- 集中モード（F）：選んだ枝だけを表示して、ほかを薄くする。Esc で解除
- バックアップのお知らせ：最後のバックアップから7日以上たつと、サイドバーに控えめに表示（「あとで」で3日後にまた）
- 狭い画面（幅 720px 以下）：左上の ☰ でマップ一覧を開く。操作方法は画面下に開く
- 画面の明るさ：ライト / ダーク / 自動（パソコン・スマホの設定に合わせる）をサイドバーの「⚙ 設定」で切り替え
- 枝の伸ばし方：右だけ / 左右（左右のときは、タイトルの右のボタンで右側・左のボタンで左側を別々にたたむ）（ツールバーで切り替え。読書は右だけ、シンプルは左右が最初の形）。左右のときは量に合わせて自動で振り分け、枝ごとに左・右・自動を選べる（画面右上の「この枝の位置」）
- 見た目のテーマ：配色・線・ノードの形のセットをサイドバーの「⚙ 設定」で切り替え（シンプル・やわらか・ノートの3つは基本テーマで無料。今後追加する細かい配色・テーマを有料にする予定）
- 自動保存（ブラウザ内の IndexedDB。外部には一切送信しない。以前の localStorage のデータは自動で引き継ぐ）
- Markdown（.md）の書き出し・読み込み：見出しと箇条書きの形。MindNode・XMind・Mindomo などほかのマインドマップや、メモアプリで開ける。引用は “ ”、ページは（p.12）として残り、読み込むと元に戻る
- ファイルへの書き出し・読み込み（`.mindmap.json`）
  - 「このマップを書き出す」「すべてバックアップ」でダウンロードフォルダに保存
  - 「ファイルを開く」または画面へのドラッグ＆ドロップで読み込み。既存のマップは上書きせず、新しいマップとして追加
- 日本語IMEの変換確定 Enter で誤動作しない

## チートシート

まずはこれだけ覚えれば使えます（Mac は ⌘ / Option、Windows は Ctrl / Alt）。

```
 つくる               うごく                     ととのえる
 Tab     → 詳しく      ← →       まとめ側 / 詳しい側   Option+↑↓  順番を入れ替え
 Enter   ↓ 並べて      ↑ ↓       上下へ              ドラッグ    別の項目へ移動
 ⌘Enter  まとめる      H         タイトルへ戻る        /          たたむ・ひらく
 Space   編集          Shift+矢印 一気に移動           ⌘Z         元に戻す
```

| よく使う | キー |
|---|---|
| → 詳しく（掘り下げた項目を追加） | Tab |
| ↓ 並べて（同じ並びの下に追加） | Enter |
| ↑ 並べて（同じ並びの上に追加） | Shift+Enter |
| まとめる（上にまとめの見出しを追加） | ⌘+Enter |
| 編集 / 確定 / 取り消し | Space / Enter / Esc |
| Enter を押し間違えた（本当は詳しく） | 空のまま Tab（逆は Shift+Tab） |
| 削除 | Delete |
| 移動 | 矢印キー |
| 一気に移動 | Shift+矢印 |
| 深さに関係なく、読む順で前・次へ | ⌘+↑↓ |
| タイトルへ戻る | H |
| 順番の入れ替え | Option+↑↓ |
| 枝をタイトルの左 / 右へ | Option+← / → |
| メモ | M |
| 検索 | ⌘F |
| 集中モード | F |
| たたむ・ひらく | / |
| コピー / 切り取り / 貼り付け / 複製 | ⌘C / ⌘X / ⌘V / ⌘D |
| 元に戻す / やり直す | ⌘Z / ⌘Shift+Z |
| 読書：引用 / ページ / 章を追加 | Q / P / C |
| ファイルに書き出す / 開く | ⌘Shift+S / ⌘O |

言葉の意味（選んでいる項目から見て）

```
              ┌── 並べた項目（上）
 まとめ側 ──┼── 選んでいる項目 ──── 詳しい側
              └── 並べた項目（下）
```

- 詳しく：選んでいる項目を掘り下げる項目。一般的なマインドマップ用語では「子」
- 並べて：同じまとめから出ている、上下に並ぶ項目。用語では「兄弟」
- まとめる：選んでいる項目の上にまとめの見出しを入れる。まとめ側の項目は用語では「親」

## 操作（詳しい一覧）

キー操作は XMind に合わせている。⌘ / Option（Mac）と Ctrl / Alt（Windows）は自動で切り替わる。

**追加・編集**

| キー | 動作 |
|---|---|
| Tab | → 詳しく：掘り下げた項目を追加（入力中でも可） |
| Enter | ↓ 並べて：同じ並びの下に追加 / 入力を確定 |
| Shift+Enter | ↑ 並べて：同じ並びの上に追加（入力中は改行） |
| ⌘(Ctrl)+Enter | まとめる：上にまとめの見出しを追加 |
| Space / F2 / ダブルクリック | 編集 |
| Esc | 入力を取り消し（追加したばかりの空の項目は消えて、元の項目に戻る） |
| 空のまま Tab / Shift+Tab | 追加したばかりの空の項目を「詳しく」に変える / 「並べて」に変える（Enter・Tab の押し間違いの修正） |
| Delete | 削除 |

**選択の移動**

| キー | 動作 |
|---|---|
| ← / → | まとめ側へ / 詳しい側へ（前にいた項目に戻る） |
| ↑ / ↓ | 同じ深さの上下へ（並びをまたぐ） |
| ⌘(Ctrl)+↑ / ↓ | 深さに関係なく、読む順（上から下へ、目次のような順番）で前・次の項目へ |
| Shift+← | 枝の先頭へ（もう一度でタイトル） |
| Shift+→ | 枝の先端へ（来た道をたどる。初めてなら一番上の枝） |
| Shift+↑ / ↓ | 並びの先頭 / 末尾へ |
| H / Home | 中心（タイトル）に戻る |

**並べ替え・整理**

| キー | 動作 |
|---|---|
| Option(Alt)+↑ / ↓ | 並びの中で順番を入れ替え |
| Option(Alt)+← / → | 枝をタイトルの左側 / 右側へ（右だけのマップは左右に広げる形になる） |
| ドラッグ | 別の項目に重ねて離すと、その詳しい項目として移動 |
| / ・ ⌘(Ctrl)+/ | 折りたたみ・展開 |
| ⌘(Ctrl)+C / X / V | コピー / 切り取り / 選んでいる項目の詳しい項目として貼り付け |
| ⌘(Ctrl)+D | 複製 |
| ⌘(Ctrl)+Z / ⌘(Ctrl)+Shift+Z | 元に戻す / やり直す |

コピーした内容は、ほかのアプリには箇条書き（Markdown）として貼り付けられる（引用は “ ”、ページは（p.12）として文章に入る）。
ほかのアプリの箇条書きや Markdown の見出しを貼り付けると、階層ごと項目になる。

**読書モード**

| キー | 動作 |
|---|---|
| Q | 引用 ⇄ 自分の言葉 |
| P | ページ番号を入力 |
| C | 章を追加 |

**ファイル**

| キー | 動作 |
|---|---|
| ⌘(Ctrl)+Shift+S | このマップをファイルに書き出す |
| ⌘(Ctrl)+O | ファイルを開く |

## 自分のパソコンで動かす（Mac）

置き場所は `~/projects/mindmap-reader` に統一する。Node.js が必要（`node -v` で確認）。

**初回**

```bash
mkdir -p ~/projects && cd ~/projects
git clone https://github.com/satoru-tak/mindmap-reader.git
cd mindmap-reader
npm install
npm run dev
```

ブラウザで http://localhost:5173 を開く。止めるときはターミナルで `Ctrl+C`。

**2回目以降（最新版にして起動）**

```bash
cd ~/projects/mindmap-reader && git pull && npm install && npm run dev
```

注意：保存されるマップは開いた場所（localhost、プレビューページ、将来の公開URL）ごとに別々。
移したいときは「すべてバックアップ」で書き出し、移したい先で「ファイルを開く」。

## 開発

```bash
npm run dev      # 開発サーバー http://localhost:5173
npm run build    # 本番用に dist/ へ出力
npx vite preview # ビルド結果の確認 http://localhost:4173
```

### 手動テスト

実際の Mac・ブラウザ・日本語入力・見た目は人が確認する。手順と期待する結果は `docs/TEST_CHECKLIST.md`。

### 全コマンドのテスト（自動）

`e2e/commands.mjs` に、キー操作・ボタン・ドラッグ・ファイルの書き出し/読み込みなど
すべてのコマンドを実際のブラウザで操作して確かめるテストがある（⌘ と Ctrl の両方を確認）。
コマンドを追加・変更したら、ここにもテストを足して実行する。

```bash
# 初回だけ
npm install --no-save playwright && npx playwright install chromium

# 毎回（ターミナルを2つ使う）
npm run build && npx vite preview --port 4173   # 1つ目
npm run test:e2e                                # 2つ目。最後に「◯件成功 / ◯件失敗」と出る
npm run test:e2e -- コピー                       # 名前に「コピー」を含むテストだけ実行
```

技術構成：Vite + React + TypeScript、[React Flow](https://reactflow.dev/)（キャンバス）、Zustand（状態管理）。

画面上の言葉とコード上の言葉の対応：項目＝node、詳しく＝child、並べて＝sibling、まとめる＝parent の挿入。

主なファイル

- `src/store.ts` … マップ・ノードの状態と操作、Undo/Redo、自動保存
- `src/storage.ts` … 保存（IndexedDB、使えないときは localStorage）
- `src/transfer.ts` / `src/FileActions.tsx` … ファイルの書き出し・読み込み
- `src/page.ts` … ページ番号の入力チェック
- `src/clipboard.ts` … コピー・貼り付け（箇条書きとの相互変換）
- `src/theme.ts` … ライト / ダーク / 自動の切り替えと、見た目のテーマ（`LOOKS`：枝の色・線の形・ノードの形・背景）。
  テーマを増やすときは `LOOKS` に1つ足し、色を変えたい場合は `src/index.css` に `:root[data-look='id']` を足す。
  ノードの形は `src/App.css` の `:root[data-shape=...]`
- `src/layout.ts` … 左→右のツリー自動レイアウト
- `src/Canvas.tsx` … React Flow のキャンバス
- `src/MindNode.tsx` … ノードの表示と編集
- `docs/PLAN.md` … 開発プラン
