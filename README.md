# Mindmap Reader

本を読みながら、内容を構造化して理解するためのマインドマップWebアプリ。
ADHD/ASDなど「頭の中を整理するのが苦手」な人が、迷わず・少ない手数で使えることを重視しています。

## 現在の段階

**段階1：操作感の検証（PoC）**。キャンバスの操作が気持ちよくできるかを確かめるための試作です。

できること

- 読書マップ（本 → 章 / 気づき・感想 / 行動に移すこと）と自由マップの作成
- ノードの追加・編集・削除（キーボードだけで完結）
- 自動整列（レイアウトは常に自動。位置調整の手間なし）
- ドラッグで別のノードに重ねると付け替え（移動先の強調表示・新しい線のプレビュー・案内文つき）
- 編集中は文字数に合わせてノードが横に伸びる（周りのノードも自動でずれる）
- 折りたたみ・展開、ズーム・パン
- 元に戻す / やり直す
- 自動保存（ブラウザ内の localStorage。外部には一切送信しない）
- 日本語IMEの変換確定 Enter で誤動作しない

## 操作

| キー | 動作 |
|---|---|
| Tab | 子を追加（入力中でも可） |
| Enter | 兄弟を追加 / 入力を確定 |
| Space / F2 / ダブルクリック | 編集 |
| Shift+Enter | 入力中に改行 |
| Esc | 入力を取り消し |
| ← / → | 親へ / 子へ（前にいた子に戻る） |
| ↑ / ↓ | 同じ階層の上下（親をまたぐ） |
| Alt(Option)+↑ / ↓ | 階層に関係なく、画面上ですぐ上・下のノードへ |
| Shift+← | 枝の先頭へ（もう一度でタイトル） |
| Shift+→ | 枝の先端へ（来た道をたどる。初めてなら一番上の枝） |
| Shift+↑ / ↓ | 兄弟の先頭 / 末尾へ |
| / | 折りたたみ・展開 |
| Delete | 削除 |
| Ctrl(⌘)+Z / Ctrl(⌘)+Shift+Z | 元に戻す / やり直す |

## 開発

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ に出力
```

技術構成：Vite + React + TypeScript、[React Flow](https://reactflow.dev/)（キャンバス）、Zustand（状態管理）。

主なファイル

- `src/store.ts` … マップ・ノードの状態と操作、Undo/Redo、自動保存
- `src/layout.ts` … 左→右のツリー自動レイアウト
- `src/Canvas.tsx` … React Flow のキャンバス
- `src/MindNode.tsx` … ノードの表示と編集
- `docs/PLAN.md` … 開発プラン
