# 名前の検討メモ

## 現状：仮決定「Clarimo（クラリモ）」

- 由来：clarity（明快さ）＋ポップな語尾。「頭の中がクリアになる」
- 方針：名前は響きで覚えてもらい、何のアプリかは説明文で伝える
  - 説明文の例：「Clarimo ― 頭の中がすっきりする思考整理マップ」
  - 英語：「Clarimo ― Turn scattered thoughts into clarity.」
- 拡張子の候補：`.clarimo`（中身は今の JSON のまま）

## 外した候補と理由

| 候補 | 理由 |
|---|---|
| ThinkClear | 同名のアプリ（ThinkClear AI）が実在。ありきたりで埋もれやすい（ChatGPT・Gemini も同意見） |
| MindClear | 同名のマインドマップアプリが実在 |
| ClearMap | 同名の地図アプリ（日本）が実在 |
| Tidymind / MindTidy / ThinkTidy | Tidy Mind（思考整理アプリ）、MindTidy Notes が実在 |
| Unravel / Untangle | 同名の「頭の中の地図」アプリ、CBT アプリが実在 |
| Mindsort | 同名のゲーム、ADHD 向けの BrainSort と紛らわしい |
| ThinkleMap | 既存の ThinkMap と1文字違い |
| Clarimap / Clariqo / Clario / Clearmindly / Cogno | 類似・同名のサービスが多い |
| NeatMind | 日本語で「ニート」に聞こえる |
| Mappio | 日本の大手地図サービス「マピオン」と音がほぼ同じ。地図アプリに埋もれやすい |
| Serevo | Serevio（飲酒管理）、Serevona（環境音）、マインドフルネスアプリと重なる。日本語で「セレブ」に聞こえる |
| Hareo | 日本語で「晴れ男」に聞こえる。英語で読み方が定まらない |
| Atamap | 日本人にしか意味が伝わらない |
| KOMICHI | 同名のお出かけアプリが実在 |
| Nodely | Nodle など似た名前が多い |
