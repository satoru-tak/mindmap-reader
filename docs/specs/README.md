# 設計書（docs/specs）

今のアプリが「どう動くか」「なぜそうしたか」をまとめた設計書です。
新しい機能を作るときや、動きを変えるときは、ここを先に更新してから実装します。

| ファイル | 内容 |
|---|---|
| [01-data-and-storage.md](01-data-and-storage.md) | データの形（マップ・項目）、保存の場所、自動保存、元に戻す |
| [02-layout.md](02-layout.md) | 自動の配置、左右の枝、線のつなぎ方、折りたたみ |
| [03-operations.md](03-operations.md) | キー操作・マウス操作・ドラッグ、選択の移動のルール |
| [04-reading-mode.md](04-reading-mode.md) | 読書モード（章の型・引用・ページ番号） |
| [05-themes.md](05-themes.md) | 画面の明るさ、見た目のテーマ、背景の模様（案） |
| [06-files.md](06-files.md) | ファイル（.mindmap.json / Markdown）とコピー・貼り付けの形 |
| [07-features.md](07-features.md) | メモ・検索・集中モード・バックアップのお知らせ・サイドバー |

## 書き方の決まり

- **状態**を見出しの横に書く：`実装済み` / `案`（まだ作っていない・決まっていない）
- 決めた日と理由を書く（あとで「なぜこうしたのか」がわかるように）
- 画面の言葉はアプリの表示どおりに書く（例：「詳しく」「並べて」「まとめる」）
- 数字（日数・幅・回数など）は、コードの値と合わせる。コードを変えたらここも直す
