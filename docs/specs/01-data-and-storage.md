# 01. データと保存 `実装済み`

## マップ（MindMap）

`src/types.ts`

| 項目 | 内容 |
|---|---|
| `id` | マップの ID |
| `title` | マップの名前。タイトル（中心の項目）の文字と常に同じ |
| `mode` | `reading`（読書）/ `free`（画面の表示は「シンプル」。昔の名前のまま保存） |
| `rootId` | タイトルの項目の ID |
| `nodes` | 項目の一覧（ID → 項目） |
| `layout` | 枝の伸ばし方 `right`（右だけ）/ `both`（左右）。なければモードの既定値（読書＝右だけ、シンプル＝左右） |
| `createdAt` / `updatedAt` | 作った日時 / 最後に変えた日時（ミリ秒） |

## 項目（MindNodeData）

| 項目 | 内容 |
|---|---|
| `id` / `parentId` | 自分の ID / 親の ID（タイトルは null） |
| `text` | 書いた文字（改行可） |
| `children` | 子の ID の並び（この順に表示） |
| `collapsed` | たたんでいるか。タイトルを左右に広げているときは「右側」をたたむ |
| `collapsedLeft` | タイトルだけ：左側の枝をたたんでいるか |
| `page` | 読書モード：ページ番号（例 `42` / `42-45` / `12, 15-18`） |
| `kind` | 読書モード：`quote`＝引用。なし＝自分の言葉 |
| `note` | メモ（長めの説明） |
| `side` | タイトルのすぐ下の枝だけ：`left` / `right`。なし＝自動 |

読書モードの情報（`page` / `kind`）は、シンプルに切り替えても消さずに隠すだけ。戻すと出てくる。

## 保存

- **場所**：ブラウザの IndexedDB（DB `mindmap-reader`、ストア `kv`、キー `state`）。外部には一切送らない
- **自動保存**：変更から 300ms 後にまとめて保存。ページを閉じる・隠すときはすぐ保存
- **読み込み**：画面を出す前に読み込んでおき、最初から前回の状態で開く
- **引き継ぎ**：以前の localStorage（`mindmap-reader:v1`）のデータがあれば、自動で IndexedDB に移す
- IndexedDB が使えないときは localStorage に保存する

### ブラウザに保存する小さな設定（localStorage）

| キー | 内容 |
|---|---|
| `mindmap-reader:theme` | 画面の明るさ（light / dark / なし＝自動） |
| `mindmap-reader:look` | 見た目のテーマ |
| `mindmap-reader:settings-open` | 「⚙ 設定」を開いているか |
| `mindmap-reader:help` | 操作方法を開いているか |
| `mindmap-reader:last-backup` | 最後に「すべてバックアップ」した日時 |
| `mindmap-reader:backup-snooze` | バックアップのお知らせを次に出してよい日時 |
| `mindmap-reader:first-seen` | 使い始めた日時 |

### 注意（決めた理由）

- データはブラウザの中だけにある。ブラウザのデータを消すと消えるので、バックアップのお知らせを出す（→ 07）
- Safari は、7日間そのサイトを開かないと保存データを消すことがある。インストール型（PWA）にすると対象外になる（→ PLAN の PWA）
- データは URL（ドメイン）ごとに保存される。公開する場所や URL を変えると、書き出し → 読み込みで移す必要がある

## 元に戻す・やり直す

- 項目の変更（追加・削除・移動・文字・メモ・ページ・引用・左右の指定など）は、変更前の状態を履歴に残す
- 履歴は最大 100 回。マップを切り替えると履歴は空になる
- 履歴に残さない変更：検索で見つけた項目を見せるために、たたまれた枝を開くこと
- 空のまま確定した新しい項目は、履歴を残さずに消す（「元に戻す」で空の項目が出てこないように）
