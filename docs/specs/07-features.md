# 07. 補助の機能とサイドバー `実装済み`

`src/Panels.tsx`、`src/Sidebar.tsx`、`src/SidePicker.tsx`

## メモ（2026-11-07）

- 項目ごとに長めのメモを書ける。マップには ≡ の印だけを出し、マップをすっきり保つ
- 開き方：M キー、ツールバーの「メモ」、項目の ≡ の印（M・「メモ」はもう一度押すと閉じる）
- メモ欄は画面の右上（「この枝の位置」の下）に出る
- 保存：欄から離れたとき・閉じたとき・別の項目を選んだとき。元に戻すの対象
- 別の項目を選ぶと、その項目のメモに切り替わる
- 閉じ方：右上の「閉じる」ボタン、Esc、⌘+Enter（Windows は Ctrl+Enter。書いているとき。2026-11-14）、M（入力欄の外にいるとき）、ツールバーの「メモ」（2026-11-14：「×」だけでは気づきにくかったため、文字のボタンに）
- 開いた直後に打った文字も入るよう、開いたらすぐ入力欄に入る
- 空にするとメモは消える（印も消える）
- 気になる点：メモ欄が右上の項目に重なることがある。邪魔なら、開いたときにマップをずらす（案）

## マップ内の検索（2026-11-07）

- 開き方：⌘+F（ブラウザの検索の代わり）、ツールバーの「検索」
- 対象：項目の文字とメモ。全角・半角、大文字・小文字の違いは無視
- 並び：読む順（上から下）。件数を「1 / 5」のように出す
- Enter / ↓ で次、Shift+Enter / ↑ で前。最後の次は最初に戻る
- 一致した項目すべてに薄い印、いま見ている一致に濃い印。その項目を選び、画面に入れる
- たたまれた枝の中の一致は、その枝を開いて見せる（元に戻すの履歴には入れない）
- Esc か × で閉じる。印も消える

## 集中モード（2026-11-07）

- F キー、またはツールバーの「集中」。選んだ枝と、タイトルまでの道だけをはっきり見せ、ほかを薄く（20%）する
- 入ったとき、その枝が画面に収まるように表示する
- もう一度 F、Esc、または左上の「解除」で戻る（戻るとマップ全体を表示）
- タイトルでは使えない（全部が対象になるため）。マップを切り替えると解除

## バックアップのお知らせ（2026-11-07）

- 最後の「すべてバックアップ」（なければ使い始め）から **7日以上**たち、その後にマップを変えていたら、サイドバーの下に控えめに出す
- 「今すぐバックアップ」：その場で全マップを保存し、お知らせを消す
- 「あとで」：**3日後**にまた出す
- ポップアップは使わない（作業を止めない、驚かせない）
- 理由：データはブラウザの中だけ。Safari は7日間開かないとデータを消すことがある

## サイドバー

- 上から：アプリ名、＋ 読書マップ / ＋ シンプルマップ、マップ一覧、（バックアップのお知らせ）、⚙ 設定
- **マップ一覧**：新しく変えた順。一覧のブロックの中だけでスクロールし、新規作成と設定はいつも同じ場所
  - 長いタイトルは1行のまま、右端を薄くして消す。切れているときだけ、約0.3秒で全文の吹き出しを出す（ブラウザ標準の吹き出しは約1秒かかり変えられないため自作。2026-11-05）
  - マウスを乗せると × が出る（ふだんは場所を取らない）。× → 「削除する / やめる」の2段階
- **⚙ 設定**（2026-11-05）：ファイル・見た目のテーマ・画面の明るさ・最初の倍率（2026-11-14 追加）をまとめ、最初は閉じておく（一覧を広く使うため）。
  閉じていても ⌘+O などのキーは使える
- **設定を開いたら、サイドバーは設定だけ**（2026-11-15）：設定の項目が増え、開くとサイドバーにスクロールバーが出て、
  マップ一覧がほとんど見えなくなったため。開いているあいだは新規作成のボタン・マップ一覧・お知らせを隠し、
  上に「← マップ一覧に戻る」を出す。設定がサイドバーに収まらない小さい画面だけ、設定の中でスクロールする
  - 開いたままにしたことは覚えない（次に開いたとき、マップ一覧が出ないと困るため）
- **狭い画面**（幅 720px 以下）：サイドバーは ☰ で開く引き出しに。操作方法は画面の下に開く
- **広い画面でも閉じられる**（2026-11-15）：サイドバーの上の「«」で閉じ、ツールバー左の「☰」で開く（狭い画面と同じ ☰ なので覚えることが増えない）
  - キー：⌘+\（Windows は Ctrl+\）で開く・閉じる（Notion などと同じ）。日本語キーボードの Mac では ¥ のキーで \ が入らないので、⌘+¥ でも動くようにする
  - 開いているか閉じているかは覚える（localStorage の `mindmap-reader:sidebar`）。狭い画面の引き出しには影響しない
- **スクロールバー**（2026-11-15）：中身がはみ出したときだけ、一覧・設定の中に細く薄いバーを出す。マウスを乗せていないときは隠す
  （Mac の「スクロールバーを常に表示」が有効でも目立たないように）
- **設定の高さを詰める**（2026-11-15）：項目の間隔を詰めて、高さ 600px 程度の画面でも、はみ出さずに収まるようにする

## ツールバー

- 左：☰（狭い画面）、読書 / シンプル、右だけ / 左右、マップの名前
- 右：→ 詳しく、↓ 並べて、まとめる、編集、削除、メモ ／ ↶ ↷ ／ 集中、検索
- 「中心へ」「全体表示」は、画面の右下の「表示の操作」に移した（2026-11-15。下記）
- **編集ボタンの表示 / 非表示**（2026-11-15）：「→ 詳しく・↓ 並べて・まとめる・編集・削除」の5つは、⚙ 設定の「編集ボタン」で隠せる
  - 5つともキーボード（Tab・Enter・⌘+Enter・Space・Delete）で操作できるので、慣れた人には要らない。画面をすっきりさせたい人向け
  - 最初は「表示する」（慣れていない人が迷わないように）
  - 「メモ・↶ ↷・集中・検索」は場面に応じて使うので、いつも出す
  - 保存する場所：localStorage の `mindmap-reader:edit-buttons`（ブラウザごと）

## 表示の操作（画面の右下）（2026-11-15）

ツールバーのボタンが増えて、幅 1280px の画面で2段に折り返していたため、画面の部品を整理する（1つ目）。
見え方を変える操作は、地図アプリと同じく右下にまとめる（「見え方は右下」と覚えやすい）。

| ボタン | 動き |
|---|---|
| 中心へ | タイトルを選び、画面の真ん中に（倍率はそのまま。H でも同じ） |
| 全体表示 | マップ全体が画面に収まるように |
| − / ＋ | 縮小 / 拡大 |
| 倍率（例：100%） | 押すと「最初の倍率」に戻す（場所はそのまま） |

- 文字のボタンにする（アイコンだけだと意味が伝わりにくいため）
- React Flow 標準の拡大縮小ボタン（縦に並ぶ小さな四角）はやめて、この横並びの1本にまとめる
- 「この枝の位置」（左 / 自動 / 右）：左右に広げたマップで、タイトル以外を選んでいるとき、画面の右上に出す

### メモを閉じるキーの検討（2026-11-14）

- Shift+M：メモ欄で書いているときは大文字の M が入ってしまうので使わない
- ⌘+Shift+M：Mac の Chrome でユーザー（プロフィール）の切り替えに使われているので使わない。⌘+M も Mac ではウインドウをしまう操作
- ⌘+Enter：Slack やメールなどで「書き終わり」に使われる組み合わせ。メモ欄の中だけで効くので、マップの「まとめる」（⌘+Enter）とぶつからない → 採用
