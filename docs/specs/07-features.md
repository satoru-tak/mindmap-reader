# 07. 補助の機能とサイドバー `実装済み`

`src/Panels.tsx`、`src/Sidebar.tsx`、`src/SidePicker.tsx`

## メモ（2026-11-07）

- 項目ごとに長めのメモを書ける。マップには ≡ の印だけを出し、マップをすっきり保つ
- 開き方：M キー、ツールバーの「メモ」、項目の ≡ の印
- メモ欄は画面の右上（「この枝の位置」の下）に出る
- 保存：欄から離れたとき・閉じたとき・別の項目を選んだとき。元に戻すの対象
- 別の項目を選ぶと、その項目のメモに切り替わる
- Esc で閉じる。開いた直後に打った文字も入るよう、開いたらすぐ入力欄に入る
- 空にするとメモは消える（印も消える）
- 気になる点：メモ欄が右上の項目に重なることがある。邪魔なら、開いたときにマップをずらす（案）

## マップ内の検索（2026-11-07）

- 開き方：⌘+F（ブラウザの検索の代わり）、ツールバーの「検索」
- 対象：項目の文字とメモ。全角・半角、大文字・小文字の違いは無視
- 並び：読む順（上から下）。件数を「1 / 5」のように出す
- Enter / ↓ で次、Shift+Enter / ↑ で前。最後の次は最初に戻る
- 一致した項目すべてに薄い印、いま見ている一致に濃い印。その項目を選び、画面に入れる
- たたまれた枝の中の一致は、その枝を開いて見せる（元に戻すの履歴には入れない）
- Esc か × で閉じる。印も消える

## 集中モード（2026-11-07）

- F キー、またはツールバーの「集中」。選んだ枝と、タイトルまでの道だけをはっきり見せ、ほかを薄く（20%）する
- 入ったとき、その枝が画面に収まるように表示する
- もう一度 F、Esc、または左上の「解除」で戻る（戻るとマップ全体を表示）
- タイトルでは使えない（全部が対象になるため）。マップを切り替えると解除

## バックアップのお知らせ（2026-11-07）

- 最後の「すべてバックアップ」（なければ使い始め）から **7日以上**たち、その後にマップを変えていたら、サイドバーの下に控えめに出す
- 「今すぐバックアップ」：その場で全マップを保存し、お知らせを消す
- 「あとで」：**3日後**にまた出す
- ポップアップは使わない（作業を止めない、驚かせない）
- 理由：データはブラウザの中だけ。Safari は7日間開かないとデータを消すことがある

## サイドバー

- 上から：アプリ名、＋ 読書マップ / ＋ シンプルマップ、マップ一覧、（バックアップのお知らせ）、⚙ 設定
- **マップ一覧**：新しく変えた順。一覧のブロックの中だけでスクロールし、新規作成と設定はいつも同じ場所
  - 長いタイトルは1行のまま、右端を薄くして消す。切れているときだけ、約0.3秒で全文の吹き出しを出す（ブラウザ標準の吹き出しは約1秒かかり変えられないため自作。2026-11-05）
  - マウスを乗せると × が出る（ふだんは場所を取らない）。× → 「削除する / やめる」の2段階
- **⚙ 設定**（2026-11-05）：ファイル・見た目のテーマ・画面の明るさをまとめ、最初は閉じておく（一覧を広く使うため）。
  閉じていても ⌘+O などのキーは使える。開閉の状態は覚える
- **狭い画面**（幅 720px 以下）：サイドバーは ☰ で開く引き出しに。操作方法は画面の下に開く

## ツールバー

- 左：☰（狭い画面）、読書 / シンプル、右だけ / 左右、マップの名前
- 右：→ 詳しく、↓ 並べて、まとめる、編集、削除、メモ ／ ↶ ↷ ／ 集中、検索 ／ 中心へ、全体表示
- 「この枝の位置」（左 / 自動 / 右）：左右に広げたマップで、タイトル以外を選んでいるとき、画面の右上に出す
