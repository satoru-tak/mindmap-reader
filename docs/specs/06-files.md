## アプリのファイル（.mindmap.json）

```json
{ "app": "mindmap-reader", "format": 1, "exportedAt": "2026-11-07T…", "maps": [ /* マップ（01 の形） */ ] }
```

- 「このマップを書き出す」（⌘+Shift+S）：開いているマップ1つ。ファイル名＝マップの名前
- 「すべてバックアップ」：全マップを1つのファイルに。ファイル名 `mindmap-backup-年月日-時分.mindmap.json`
- 読み込み（「ファイルを開く」⌘+O、または画面にドロップ）
  - 中身を検査し、タイトルからたどれる項目だけで作り直す（壊れたデータ・循環を除く）
  - いつも新しいマップとして追加し、既存のマップは上書きしない（ID は振り直す）
  - 同じ名前のマップがあれば「（2）」を付ける
  - 残す情報：文字・子の並び・たたみ・ページ・引用・メモ・左右の指定・枝の伸ばし方

## Markdown（.md）

ほかのマインドマップ（MindNode・XMind・Mindomo など）やメモアプリと行き来するための形。
主なマインドマップアプリは Markdown / OPML / FreeMind でやり取りできるので、XMind の独自形式への対応は見送り（2026-11-07）。

### 書き出し（「Markdown で書き出す」）

```markdown
# 本のタイトル

## 第1章

- 要点
  > 要点のメモ
  - 大事なこと
- “引用”（p.12）
- 気づき

## 全体の気づき・感想
```

- タイトル＝`#`、タイトルのすぐ下＝`##`、それより下＝字下げした箇条書き（2文字ずつ）
- 引用は “ ” で囲み、ページは（p.12）を後ろに付ける
- メモは `> ` で始まる行として、その項目のすぐ下に書く
- 項目の中の改行は空白にする

### 読み込み

- `.md` / `.markdown` / `.txt` を、ファイルを開く・ドロップで読み込む
- 見出し（`#`）の深さと、箇条書きの字下げを階層にする
- 一番上の見出しが1つだけならそれをタイトルに。複数ならファイル名をタイトルにして、その下に並べる
- “…” は引用に、（p.12）はページ番号に、`> ` の行はすぐ上の項目のメモに戻す
- 引用かページがあれば読書マップ、なければシンプルマップとして作る

## コピー・貼り付け

- ⌘+C / ⌘+X：選んだ項目を枝ごとコピー / 切り取り
  - アプリの中では、引用・ページ・メモ・たたみも含めてそのまま貼り付けられる
  - ほかのアプリには、字下げした箇条書きの文章として貼り付けられる（引用は “ ”、ページは（p.12）、メモは `> ` の行）
- ⌘+V：選んだ項目の「詳しく」（子）として貼り付け
  - ほかのアプリからの文章は、字下げ・箇条書きの記号（- * + • ・ 1.）・見出し（#）を見て階層にする
- Safari 対策：入力欄の外では copy / paste イベントが出ないことがあるので、キーで処理し、
  paste イベントが 80ms 来なければアプリの中でコピーしたものを貼り付ける
