# 05. 見た目（明るさ・テーマ・背景）

`src/theme.ts`、`src/index.css`（色）、`src/App.css`（形）

## 画面の明るさ `実装済み`

- ライト / ダーク / 自動（パソコン・スマホの設定に合わせる）。「⚙ 設定」で選ぶ
- ダークは真っ黒・真っ白を避けた、まぶしくない色
- 色はすべて CSS 変数。`:root[data-theme='dark']` でダーク用の値に切り替わる

## 見た目のテーマ `実装済み`

1つのテーマ＝次の部品のセット（`LOOKS`）。

| 部品 | 値 |
|---|---|
| 枝の色 | 7色 × ライト用・ダーク用 |
| 線 | 形（曲線 `default` / 直角 `smoothstep` など）と太さ（第1階層 / それより下） |
| ノードの形 | `card`（角丸・色の帯）/ `pill`（丸）/ `underline`（下線） |
| 背景の模様 | `dots`（点）/ `lines`（方眼） |

| テーマ | 枝の色 | 線 | 形 | 背景 | 区分 |
|---|---|---|---|---|---|
| シンプル（標準） | 落ち着いた7色 | 曲線 2.5 / 1.75 | カード | 点 | 基本（無料） |
| やわらか | パステル | 曲線 4 / 3 | 丸 | 点 | 基本（無料） |
| ノート | インク風 | 直角 2 / 1.5 | 下線 | 方眼 | 基本（無料） |

- 今あるテーマはすべて基本テーマ（無料）。今後追加するテーマ・細かい配色を有料にする（2026-11-05 決定）
- 選んだテーマはブラウザに保存。マップごとではなく、アプリ全体で1つ
- テーマを足すとき：`LOOKS` に1つ足す。色を変えるなら `index.css` に `:root[data-look='id']`（ライト用は `:not([data-theme='dark'])` を付ける）
- 落ち着いた（刺激の少ない）見た目は必ず無料で残す。OS の「視差効果を減らす」設定ではアニメーションを止める

## 背景の模様の設定 `案`（2026-11-07 検討中）

### きっかけ

- ノートの背景は「罫線」のつもりだったが、使っている部品（React Flow の Lines）は縦横に線を引くので方眼になっていた。方眼のままでよい（本人：罫線は見づらそう）
- 方眼は「位置の手がかりになって落ち着く」人もいれば、「線が多くてちらつく」人もいる。どちらも選べるようにしたい

### 決めること

| 案 | 内容 | よいところ | 気になるところ |
|---|---|---|---|
| A. 全体で ON / OFF | 「⚙ 設定」に「背景の模様を表示」。OFF なら、どのテーマでも無地 | 設定が1つでわかりやすい | テーマごとに変えたい人には足りない |
| B. テーマどおり / 点 / 方眼 / なし | 「⚙ 設定」で背景だけ選び直せる。「テーマどおり」が既定 | 好きな組み合わせにできる | 選択肢が増える |
| C. テーマごとに覚える | 例：ノートは方眼、シンプルは無地…をテーマごとに保存 | テーマを切り替えても好みが残る | しくみが複雑。設定の場所がわかりにくい |

- Claude の案：**A（ON / OFF）から始める**。設定を増やしすぎない方針（ADHD/ASD 向けに選択肢を絞る）に合う。
  要望が出たら B に広げる（A の OFF は B の「なし」と同じなので、あとから広げやすい）
- あわせて、ノートの方眼を今より薄くする
- 無料（見やすさのための設定なので）
