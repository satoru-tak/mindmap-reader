# 05. 見た目（明るさ・テーマ・背景）

`src/theme.ts`、`src/index.css`（色）、`src/App.css`（形）

## 画面の明るさ `実装済み`

- ライト / ダーク / 自動（パソコン・スマホの設定に合わせる）。「⚙ 設定」で選ぶ
- ダークは真っ黒・真っ白を避けた、まぶしくない色
- 色はすべて CSS 変数。`:root[data-theme='dark']` でダーク用の値に切り替わる

## 見た目のテーマ `実装済み`

1つのテーマ＝次の部品のセット（`LOOKS`）。

| 部品 | 値 |
|---|---|
| 枝の色 | 7色 × ライト用・ダーク用 |
| 線 | 形（曲線 `default` / 直角 `smoothstep` など）と太さ（第1階層 / それより下） |
| ノードの形 | `card`（角丸・色の帯）/ `pill`（丸）/ `underline`（下線） |
| 背景の模様 | `dots`（点）/ `lines`（方眼） |

| テーマ | 枝の色 | 線 | 形 | 背景 | 区分 |
|---|---|---|---|---|---|
| シンプル（標準） | 落ち着いた7色 | 曲線 2.5 / 1.75 | カード | 点 | 基本（無料） |
| やわらか | パステル | 曲線 4 / 3 | 丸 | 点 | 基本（無料） |
| ノート | インク風 | 直角 2 / 1.5 | 下線 | 方眼 | 基本（無料） |

- 今あるテーマはすべて基本テーマ（無料）。今後追加するテーマ・細かい配色を有料にする（2026-11-05 決定）
- 選んだテーマはブラウザに保存。マップごとではなく、アプリ全体で1つ
- テーマを足すとき：`LOOKS` に1つ足す。色を変えるなら `index.css` に `:root[data-look='id']`（ライト用は `:not([data-theme='dark'])` を付ける）
- ノート（ライト）の引用の背景は、蛍光ペンを引いたような黄色（`#f8eccd`）。それまでの薄い色は紙の色とほぼ同じで、引用かどうか見分けにくかった（2026-11-15）
- 落ち着いた（刺激の少ない）見た目は必ず無料で残す。OS の「視差効果を減らす」設定ではアニメーションを止める

## 背景の模様の設定 `案`（2026-11-07 検討中）

### きっかけ

- ノートの背景は「罫線」のつもりだったが、使っている部品（React Flow の Lines）は縦横に線を引くので方眼になっていた。方眼のままでよい（本人：罫線は見づらそう）
- 方眼は「位置の手がかりになって落ち着く」人もいれば、「線が多くてちらつく」人もいる。どちらも選べるようにしたい

### 決めること

| 案 | 内容 | よいところ | 気になるところ |
|---|---|---|---|
| A. 全体で ON / OFF | 「⚙ 設定」に「背景の模様を表示」。OFF なら、どのテーマでも無地 | 設定が1つでわかりやすい | テーマごとに変えたい人には足りない |
| B. テーマどおり / 点 / 方眼 / なし | 「⚙ 設定」で背景だけ選び直せる。「テーマどおり」が既定 | 好きな組み合わせにできる | 選択肢が増える |
| C. テーマごとに覚える | 例：ノートは方眼、シンプルは無地…をテーマごとに保存 | テーマを切り替えても好みが残る | しくみが複雑。設定の場所がわかりにくい |

- Claude の案：**A（ON / OFF）から始める**。設定を増やしすぎない方針（ADHD/ASD 向けに選択肢を絞る）に合う。
  要望が出たら B に広げる（A の OFF は B の「なし」と同じなので、あとから広げやすい）
- あわせて、ノートの方眼を今より薄くする
- 無料（見やすさのための設定なので）

## 文字の選択 `案`（2026-11-15）

### きっかけ

- たたんだときの数字が、Mac のヒラギノでは少し下に寄って見えた。文字によって見え方が変わる
- 読みやすい文字は人によって違う。ADHD / ASD・ディスレクシア（読み書きの困難）の人の中には、文字の形で読みやすさが大きく変わる人がいる
- 多言語化（英語から）を予定している。今の文字の設定は日本語の文字を先に使うので、英語の画面でも英数字がヒラギノになる

### 案

- 「⚙ 設定」に「文字」を足す。選択肢は絞る（最初は2つ、あとで1つ足す）

| 選択肢 | 内容 | 区分（案） |
|---|---|---|
| 標準 | パソコン・スマホに入っている文字（今と同じ） | 無料 |
| 読みやすさ重視 | UD の文字。日本語は BIZ UDゴシック、英語は Atkinson Hyperlegible など | 無料（使いやすさに関わるため。料金の案では文字は有料側なので、要決定） |
| 手書き風 | 手書き風テーマと一緒に（下記） | 有料の候補 |

- **文字の大きさ**（小 / 標準 / 大）も一緒に選べるようにする案。見やすさのための設定なので無料
- 選んだ文字はブラウザに保存（localStorage `mindmap-reader:font`）。アプリ全体で1つ
- テーマとは別に選ぶ（どのテーマでも読みやすい文字を使えるように）。ただし手書き風テーマは手書き風の文字を既定にする

### 多言語化とのつながり

- ページの言語（`<html lang>`）を画面の言語に合わせる。中国語・韓国語・日本語では同じ漢字でも国ごとに字の形が違うため、言語に合った文字を出すのに必要
- 文字の指定は言語ごとに分ける（例：英語の画面では英語の文字を先に、日本語の画面では日本語の文字を先に）。CSS 変数 `--font` にまとめ、言語と選んだ文字で切り替える
- 数字や記号など、言語に関係なく形をそろえたい部分（たたんだときの数字など）は、英数字用の文字を使う（`.collapse-btn .count`）

### 気をつけること

- **読み込みの量**：日本語の文字は数MBある。Google Fonts などは使う字の分だけ少しずつ読み込むので、選んだ人だけ少し重くなる程度で済む。PWA にしたあとオフラインでも使えるよう、読み込んだ文字を残すかは PWA のときに決める
- **利用条件**：使う前に、文字ごとにライセンス（無料で商用に使えるか、アプリに入れてよいか）を確かめる
- **線の位置**：文字を変えると項目の高さが変わる。自動整列は実際の大きさを測って並べているので、そのまま動くはずだが、ノートの下線がずれないか確かめる
- 多言語化と一緒に進める（文字のしくみを2回作り直さないため）

## これからのテーマ `案`
