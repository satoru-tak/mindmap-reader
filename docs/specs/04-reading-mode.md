# 04. 読書モード `実装済み`

## 新しい読書マップの型

```
本のタイトル
├─ 第1章
│   ├─ 要点
│   ├─ 引用
│   └─ 気づき
├─ 全体の気づき・感想
└─ 全体で行動に移すこと
```

- 「＋ 章を追加」（C）：今ある章の番号の一番大きい数の次の番号で、最後の章の下（全体のまとめの上）に追加。
  中身は 要点・引用・気づき。追加した章は少しの間ハイライトする（2026-11-03 の手動テストで決定）

## 引用と自分の言葉

- 項目ごとに「自分の言葉」（既定）か「“ 引用」（Q で切り替え）
- 引用は背景色と “ の印で見分ける。左の色の帯は、ほかの項目と同じく枝の色（2026-11-05）

## ページ番号

- 入力（P）：`42`、`42-45`、`12, 15-18` の形
- 入力中：全角の数字は半角に、いろいろなダッシュ（〜 ー – など）は `-` に、読点・空白は `,` に。それ以外の文字は入らない
- 確定時：範囲が逆なら入れ替える（45-42 → 42-45）、`42-42` は `42` に、空の部分は消す
- 項目の右に `p.42` の印を出す

## 読書モードの帯（画面の上）

- 「種類（自分の言葉 / “ 引用）・ページ」と「＋ 章を追加」を並べる。読書モードのときだけ出す（シンプルとの違いが一目でわかるように）
- 項目を選んでいないとき・タイトルを選んでいるときは、種類とページの欄を薄く（押せない状態に）する
- 以前は「項目を選ぶと、種類とページを設定できます」の案内文も出していたが、帯がごちゃごちゃして見えるのでやめた（2026-11-15）。
  欄が薄いことで「今は使えない」ことは伝わる
- 検討して見送った案（2026-11-15）
  - 帯をやめて、選んだ項目の近くに小さな欄を出す：メモ欄などの浮いた部品が増えて見づらくなる
  - 種類・ページをメモと一緒の「項目の詳細」パネルにまとめる：メモとは意味合いが違い、読書モードとシンプルの違いも分かりにくくなる

## シンプルとの切り替え

- ツールバーで 読書 ⇄ シンプル。読書の情報（引用・ページ）は消さずに隠す
- 枝の伸ばし方を自分で決めていないマップは、モードの既定値（読書＝右だけ、シンプル＝左右）に合わせて変わる

## これからの検討（案）

- 章以外の区切りの単位（幕・場、話・巻）：設計がまだ。単位をマップごとに選ぶ案（PLAN の課題1）
