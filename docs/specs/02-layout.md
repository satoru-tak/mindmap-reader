# 02. 配置（レイアウト） `実装済み`

`src/layout.ts`、`src/Canvas.tsx`

## 自動の配置

- 位置はすべて自動で決まる。手で動かして置く機能はない（迷わない・整理の手間をなくすため）
- タイトルが中心。子は親の外側（右の枝なら右、左の枝なら左）に並ぶ
- 各項目は、自分と子孫が入る「帯」を持つ。親は帯の中で、子の並びに合わせた高さに置く
- 項目の大きさは、文字の長さからあらかじめ計算する（Canvas で文字の幅を測る）

| 値 | 内容 |
|---|---|
| 横のすき間 `H_GAP` | 56px |
| 縦のすき間 `V_GAP` | 12px |
| 項目の最大幅 | 300px（超えたら折り返す） |
| 入力中の最大幅 | 480px（入力中は横に伸び、まわりの項目も自動でずれる） |
| 文字の大きさ | タイトル 18px / 第1階層 15px / それより下 14px |

## 左右の枝

- マップごとに **右だけ / 左右** を選ぶ（ツールバー）。既定値：読書＝右だけ（本の順に上から読める）、シンプル＝左右
- **自動の振り分け**（左右のとき）：タイトルのすぐ下の枝を上から順に見て、右側の高さが全体の半分になるまで右に置く。残りは左。
  一度左になったら、それより後ろの枝はすべて左（上からの順番を保つ）
- **自分で決める**：枝ごとに 左 / 自動 / 右（`side`）。決めた枝はその側に置き、残りを自動で振り分ける
- 振り分けは、たたんだ枝も含めて計算する（片側をたたんでも、枝の左右が入れ替わらないように）
- 左側の枝は、左右を反転して描く（線は親の左から出て子の右に入る、カードの色の帯は右、たたむボタンは左）

## 線のつなぎ方

- 線の形はテーマで決まる（曲線 / 直角）。太さは第1階層とそれより下で変える
- **カード・丸の形**：線はノードの真ん中の高さにつなぐ。親は子の並びの真ん中の高さに置く
- **下線の形**（ノートのテーマ）：線はノードの下の端（下線の高さ）につなぐ
  - 下線は CSS の枠ではなく、つなぐ線の続きとして1本の線で描く（拡大率によって線と下線が 1px ずれるのを防ぐ。2026-11-05）
  - 親の下線は、最初の子と最後の子の下線のちょうど中間に置く。子が1つ（または奇数個の真ん中）なら、親と子の下線が一直線になる

## 折りたたみ

- たたむと子孫が隠れ、ボタンに隠れた数を出す
- タイトルを左右に広げているときは、**右のボタンで右側、左のボタンで左側**を別々にたたむ（2026-11-07）。`/` は両側まとめて
- たたんだ（開いた）項目は**選ばれ**、**画面上の同じ位置に留まる**（2026-11-05）
  - 以前は、選択が前の項目（タイトルなど）に残り、「選んだ項目を画面に入れる」動きでタイトルへ画面が飛んでいた

## 画面の追いかけ

- 選んだ項目が画面の端（40px 以内）に寄ったら、その項目が真ん中に来るように画面を動かす（倍率はそのまま）
- 項目を足したとき、親やタイトルは子の真ん中に置き直されるので少し動く。作業している場所は動かないので、このままとする（2026-11-05）
- 「全体表示」：マップ全体が入るように表示。「中心へ」（H）：タイトルを真ん中に
