# 03. 操作 `実装済み`

`src/App.tsx`（キー）、`src/store.ts`（動き）、`src/Canvas.tsx`（ドラッグ）

キー配置は XMind に合わせる。Mac の ⌘ / Option と、Windows の Ctrl / Alt は自動で切り替わる。
画面の言葉は「親・子・兄弟」ではなく「まとめる・詳しく・並べて」を使う（ふつうの人にわかりやすく）。

## 追加・編集

| キー | 動き |
|---|---|
| Tab | 詳しく：子を追加してすぐ入力（入力中でも可） |
| Enter | 並べて：下に兄弟を追加 ／ 入力中は確定 |
| Shift+Enter | 並べて：上に兄弟を追加（入力中は改行） |
| ⌘+Enter | まとめる：選んだ項目の上に、まとめの見出し（親）を差し込む |
| Space / F2 / ダブルクリック | 編集 |
| Esc | 入力を取り消し。空の新しい項目は消えて、元にいた項目に戻る |
| 空のまま Tab / Shift+Tab | Enter を押し間違えたとき：今追加した空の項目を「詳しく」（子）に変える / 逆 |
| Delete / Backspace | 削除（タイトルは消せない） |
| ⌘+D | 複製 |
| M | メモを開く（→ 07） |

- 日本語入力の変換中の Enter は確定に使わない
- 新しいマップを作ると、タイトルが全選択された入力状態で開く

## 選択の移動

| キー | 動き |
|---|---|
| ← / → | まとめ側（親）へ / 詳しい側（子）へ。→ は前にいた子に戻る |
| ↑ / ↓ | 画面上で同じ深さの上下へ（並びをまたぐ）。同じ側（左右）だけ |
| ⌘+↑ / ↓ | 深さに関係なく、読む順（アウトライン順）で前 / 次 |
| Shift+← | 枝の先頭へ（もう一度でタイトル） |
| Shift+→ | 枝の先端へ（来た道をたどる） |
| Shift+↑ / ↓ | 並びの先頭 / 末尾へ |
| H / Home | タイトルへ |

- **左側の枝では ← / → が反転**：← で詳しい側、→ でタイトル側（見た目の向きと合わせる）
- タイトルからは → で右の枝、← で左の枝へ。その側がたたまれていれば開く
- → でたたまれた項目に進もうとすると、まず開く

## 並べ替え・整理

| 操作 | 動き |
|---|---|
| Option+↑ / ↓ | 並びの中で順番を入れ替え |
| Option+← / → | 枝をタイトルの左側 / 右側へ。右だけのマップでは「左右」に切り替わる |
| / ・ ⌘+/ | 折りたたみ・展開 |
| ⌘+C / X / V | コピー / 切り取り / 詳しい項目として貼り付け（→ 06） |
| ⌘+Z / ⌘+Shift+Z（⌘+Y） | 元に戻す / やり直す |

## ドラッグ

- 項目を別の項目に重ねて離すと、その項目の「詳しく」（子）として移動
- 移動先の決め方：① マウスの下の項目 → ② ドラッグ中の項目の左端の下 → ③ 右端の下 → ④ いちばん重なっている項目
- 移動中は、移動先を強調し、点線の「影」と線で行き先を見せる。自分の子孫や、今の親には落とせない（理由を表示）
- **左右に広げたマップ**：タイトルに落とすと、マウスがタイトルの左半分なら左の枝、右半分なら右の枝になる。今の親（タイトル）に落としても、反対側なら左右だけが変わる

## その他のキー

| キー | 動き |
|---|---|
| ⌘+F | 検索（→ 07） |
| F | 集中モード（→ 07） |
| ⌘+S | 保存は自動なので、書き出し方（⌘+Shift+S）を案内する |
| ⌘+Shift+S | このマップを書き出す |
| ⌘+O | ファイルを開く |
| Q / P / C | 読書モード：引用の切り替え / ページ番号 / 章を追加（→ 04） |

- Safari では、文字の入力欄の外で copy イベントが出ないことがあるため、⌘C / ⌘V はキーの押下で処理する
