# パターンの一覧（見た目・マップの種類）

今あるもの・予定のもの・無料か有料かを一か所にまとめる。
有料の範囲は「案」。課金を入れるときに最終決定する。

## 1. 見た目

### 1-1. 画面の明るさ（実装済み・無料）

| 選択肢 | 内容 |
|---|---|
| ライト | 明るい画面 |
| ダーク | 暗い画面（真っ黒・真っ白を避けた、まぶしくない色） |
| 自動 | パソコン・スマホの設定に合わせる |

どのテーマにもライト版とダーク版がある。

### 1-2. テーマ（完成したセット）

| テーマ | 枝の色 | 線 | ノードの形 | 背景 | 区分 | 状態 |
|---|---|---|---|---|---|---|
| シンプル | 落ち着いた7色 | 曲線（太さ 2.5 / 1.75） | カード（角丸・左に色の帯） | 点 | 無料・標準 | 実装済み |
| やわらか | パステル7色 | 曲線（太め 4 / 3） | 丸（色つきの背景） | 点 | 有料予定 | 見本として実装 |
| ノート | 濃いめ7色（インク風） | 直角（2 / 1.5） | 下線（線が下線につながる） | 罫線 | 有料予定 | 見本として実装 |

### 1-3. テーマを作っている部品

テーマは次の部品の組み合わせ。部品は `src/theme.ts` の `LOOKS` で指定する。

| 部品 | 今ある選択肢 | すぐ足せるもの |
|---|---|---|
| 枝の色 | 3セット（標準 / パステル / インク）×ライト・ダーク | モノクロ、低刺激（さらに淡い）、色覚に配慮した配色 |
| 線の形 | 曲線、直角（角が丸い） | 直線、直角（角がとがった） |
| 線の太さ | 2段階（第1階層 / それより下） | 細い・普通・太い の選択 |
| ノードの形 | カード、丸、下線 | 四角、枠なし（文字だけ） |
| 背景 | 点、罫線 | なし（無地） |
| 中心（タイトル）の色 | テーマごとに1色 | — |
| 文字 | 1種類（ヒラギノ / Noto Sans JP など） | 丸ゴシック、明朝、UDフォント |

## 2. マップの種類

| 種類 | 内容 | 状態 |
|---|---|---|
| 読書 | ページ番号、引用 / 自分の言葉、章の型（要点・引用・気づき）、全体の気づき・行動 | 実装済み |
| シンプル | 余計な項目のない普通のマインドマップ | 実装済み |
| 会議 | 聞きながら素早く書く（議題・決定・宿題など） | 予定 |
| ロジック | 問い → 答え → 理由 | 予定 |
| 映画 / アニメ / ビジネス など | 用途に合った型と項目 | 案 |

読書マップの区切りの単位：章（実装済み）。幕・場 / 話・巻（予定）

## 3. 無料と有料の分け方（案・2026-11-05）

考え方：**基本は無料で自由に使える**。**細かいこだわり・特定の用途向け**を有料にする。
落ち着いた（刺激の少ない）見た目は必ず無料で残す。

| | 無料 | 有料 |
|---|---|---|
| 明るさ | ライト / ダーク / 自動 | — |
| 見た目 | 基本テーマ「シンプル」。部品（線の形・ノードの形・背景・基本の配色）を自分で組み合わせて変えられる（※要確認） | 凝った完成テーマ（やわらか・ノートなど）、細かい配色（色を1本ずつ選ぶ）、文字の種類、ノードごとの色やアイコン |
| マップの種類 | 読書・シンプル・会議（基本の用途） | 細かい用途向けのマップ（映画・アニメ・ビジネスなど） |
| 保存 | ブラウザ内（完全ローカル）、ファイルへの書き出し | クラウド保存・端末間の同期（サブスク） |
| AI | — | AIモード（将来・サブスク） |

※要確認：「基本テーマを自由に変えたい」が「部品を自分で組み合わせられる」の意味で合っているか
