## 1. 見た目

### 1-1. 画面の明るさ（実装済み・無料）

| 選択肢 | 内容 |
|---|---|
| ライト | 明るい画面 |
| ダーク | 暗い画面（真っ黒・真っ白を避けた、まぶしくない色） |

どのテーマにもライト版とダーク版がある。

### 1-2. テーマ（完成したセット）

| テーマ | 枝の色 | 線 | ノードの形 | 背景 | 区分 | 状態 |
|---|---|---|---|---|---|---|
| シンプル | 落ち着いた7色 | 曲線（太さ 2.5 / 1.75） | カード（角丸・左に色の帯） | 点 | 基本（無料）・標準 | 実装済み |
| やわらか | パステル7色 | 曲線（太め 4 / 3） | 丸（色つきの背景） | 点 | 基本（無料） | 実装済み |
| ノート | 濃いめ7色（インク風） | 直角（2 / 1.5） | 下線（線と下線を1本で描く） | 罫線 | 基本（無料） | 実装済み |

### 1-3. テーマを作っている部品

テーマは次の部品の組み合わせ。部品は `src/theme.ts` の `LOOKS` で指定する。

| 部品 | 今ある選択肢 | すぐ足せるもの |
|---|---|---|
| 枝の色 | 3セット（標準 / パステル / インク）×ライト・ダーク | モノクロ、低刺激（さらに淡い）、色覚に配慮した配色 |
| 線の形 | 曲線、直角（角が丸い） | 直線、直角（角がとがった） |
| 線の太さ | 2段階（第1階層 / それより下） | 細い・普通・太い の選択 |
| ノードの形 | カード、丸、下線 | 四角、枠なし（文字だけ） |
| 背景 | 点、罫線 | なし（無地） |
| 中心（タイトル）の色 | テーマごとに1色 | — |
| 文字 | 1種類（ヒラギノ / Noto Sans JP など） | 丸ゴシック、明朝、UDフォント |

## 2. マップの種類

| 種類 | 内容 | 状態 |
|---|---|---|
| 読書 | ページ番号、引用 / 自分の言葉、章の型（要点・引用・気づき）、全体の気づき・行動 | 実装済み |
| シンプル | 余計な項目のない普通のマインドマップ | 実装済み |
| 会議 | 聞きながら素早く書く（議題・決定・宿題など） | 予定 |
| ロジック | 問い → 答え → 理由 | 予定 |
| 映画 / アニメ / ビジネス など | 用途に合った型と項目 | 案 |

読書マップの区切りの単位：章（実装済み）。幕・場 / 話・巻（予定）

## 4. 見た目の検討メモ（2026-11-07）

- ノートの背景は「罫線」と書いていたが、実際は方眼（React Flow の Lines は縦横に線を引く）。方眼のままでよい（本人：罫線は見づらそう）
- ADHD/ASD の人の感じ方は人によって違う。方眼は「位置の手がかりになって落ち着く」人もいれば、「線が多くてちらつく」人もいる
  - 案：方眼を今より薄くする ＋ 背景の模様を消せる設定（無料・誰でも使える）
- 温かみは、紙の色（生成り）・インク色の線・角の丸さ・少しゆらいだ線・文字の形から出る
- 案：**手書き風テーマ**（有料テーマの最初の候補）。手書き風の文字＋少しゆらいだ線。
  文字の候補：Klee One、Yomogi など（Google Fonts。使う前に利用条件を確認する）。
  手書き風の文字は人によって読みにくいので、標準にはせず選べるテーマの1つにする
